# OpenTypeless 한국어 로컬 받아쓰기 계획 초안

작성일: 2026-11-16. 상태: 개발 진행 지시를 반영한 계획. 로컬 STT 구현과 UI 전환을 진행 중이다. CMake와 네이티브 하위 의존성의 검사 한계에 대해 추가 승인을 받았고 cargo check가 통과했다.

동기화 기준: [인터랙티브 HTML 계획서](local-stt-plan.packed.html).

## 확정된 기술 스택

새 애플리케이션 로직은 Rust로 개발한다. UI는 React에 shadcn/ui와 Tailwind CSS를 사용한다. 기존 화면 흐름과 기능은 재사용하고, 컨트롤·레이아웃·스타일은 이 UI 스택에 맞춘다. Whisper 네이티브 엔진은 Rust 어댑터로 연결하며 내부 C/C++ FFI 사용은 허용하는 설계다.

## 목표와 범위

가입, 로그인, 외부 API 키, 별도 로컬 서버 없이 한국어 음성을 텍스트로 입력한다. 첫 실행에서 모델 다운로드·검증·자동 설정을 완료한 후 네트워크를 차단해도 녹음부터 텍스트 입력까지 완료한다. 기존 단축키, 녹음, 캡슐 UI, 사전, 클립보드 및 키보드 출력을 재사용한다.

이번 초안의 권장 범위는 macOS Apple Silicon, 받아쓰기 전용이다. 다른 플랫폼은 기존 동작을 보존하되 로컬 엔진 지원 대상으로 확약하지 않는다. OS·칩·메모리는 사용자 확인 전 가정이다. 문장 재작성, 번역, Ask Anything과 로컬 LLM은 첫 버전에서 제외한다.

## 현재 근거

현재 작업 폴더에 upstream 소스를 가져왔다. 계획의 기준은 upstream 커밋 `f5ad60298f535e0fff716a749802138ee409dea7`의 일부 파일을 읽었다. 아래 줄 번호는 변경 전 upstream 기준이다. 현재 구현의 위치와 다를 수 있다.

- `src-tauri/src/stt/mod.rs:56`: 기존 `SttProvider`는 connect, send_audio, recv_transcript, disconnect를 제공한다. 내장 엔진도 이 계약에 맞춘다.
- `src-tauri/src/stt/mod.rs:71`: `create_provider()`가 엔진 생성 지점이다. 로컬 엔진을 이곳에 추가한다.
- `src-tauri/src/pipeline.rs:2982`: `pre_warm()`은 STT와 LLM의 HTTP 엔드포인트를 준비한다. 로컬 모드에서는 HTTP 요청 대신 모델 준비만 허용한다.
- `src-tauri/tauri.conf.json:70`: updater 설정이 있다. 로컬 모드의 네트워크 차단은 STT 공급자 선택만으로 완성되지 않는다.
- `src-tauri/Cargo.toml`: 현재 HTTP 및 updater 관련 의존성이 있다. 모든 사용처 확인 전 일괄 삭제하지 않는다.
- `src/components/Onboarding/`, `src/components/Settings/`: 계정과 공급자 설정 UI가 존재한다. 구현 시 각 사용처와 테스트를 추적한다.

소스: https://github.com/tover0314-w/opentypeless/tree/f5ad60298f535e0fff716a749802138ee409dea7

## 사용자는 계정 없이 시작한다

첫 실행 화면은 마이크·접근성 권한, 모델 다운로드·자동 설정, 짧은 테스트만 보여준다. 계정, 결제, API 키, 클라우드 공급자 선택은 로컬 전용 배포에 표시하지 않는다. 저장된 과거 설정이 클라우드를 지정해도 로컬 전용 빌드는 이를 실행하지 않는다. 기존 데이터와 키를 자동 삭제하지 않는다.

영향 범위: Onboarding, Settings, 설정 저장소, 공급자 검증, 시작 시 계정 복구와 백그라운드 작업. 정확한 파일 목록과 줄 번호는 전체 checkout 확보 후 확정한다.

## 사용자는 같은 앱 안에서 Whisper로 받아쓴다

권장 구현은 whisper.cpp 계열의 네이티브 엔진을 앱 프로세스에서 호출하는 방식이다. 최종 Rust 바인딩과 버전은 설치 보안 검사 및 빌드 실험 후 선택한다. 필요한 바인딩과 UI 의존성은 AGENTS.md의 설치 전 보안 검사 절차를 거쳐 도입한다.

처리 흐름:

`단축키 → 기존 녹음 → 16 kHz mono 변환 → 로컬 STT → 기존 사전 교정 → 기존 출력`

모델은 백그라운드 작업에서 준비하고 추론한다. UI 스레드를 막지 않는다. 우선 녹음을 끝낸 후 한 번에 전사하며, 실시간 부분 전사는 추가하지 않는다. 언어는 한국어로 지정하고 task는 transcribe로 고정한다. 세션 ID와 취소 상태를 확인해 취소되거나 오래된 결과가 입력되지 않도록 한다. 동시 추론은 하나로 제한한다. 오디오 버퍼와 녹음 시간에 상한을 두고, 오래된 결과나 중복 결과가 입력되지 않도록 한다.

후보 기본 모델은 large-v3-turbo이다. large-v3는 비교 평가용으로 둔다. 양자화 수준과 최종 기본값은 대상 하드웨어의 한국어 오류·메모리·지연 비교 후 결정한다. 기존 공개 평가를 사용자 정확도 보장으로 사용하지 않는다.

예상 변경: STT 구현 파일 추가, 공급자 factory·config·capabilities, pipeline, 설정 타입·기본값, 오류 메시지, Cargo 및 패키징, 해당 테스트. 기존 사전 교정이 LLM 호출과 결합돼 있는지는 추가 확인한다. Onboarding·Settings·캡슐 화면의 컨트롤은 shadcn/ui를 사용하고 레이아웃과 스타일은 Tailwind CSS로 구현한다.

## 사용자는 모델과 오류 상태를 이해한다

상태는 모델 없음 → 파일 선택 → 검증 → 준비 → 녹음 → 전사 → 입력 완료로 구분한다. 검증 실패, 권한 거부, 무음, 메모리 부족, 취소, 입력 실패는 각각 안내한다.

첫 설치와 설정 화면에서 large-v3-turbo Q5_0(574,041,195바이트) 또는 large-v3 Q5_0(1,081,140,203바이트)을 선택해 다운로드하고 자동 설정한다. turbo는 빠른 받아쓰기용, large-v3는 정확도를 우선해 비교할 모델로 간단히 설명한다. 선택만으로 활성 모델을 교체하지 않고 다운로드·검증 완료 후 적용한다. 배포 리비전과 SHA256은 코드에 고정한다. 사용자 동작으로 시작하며 진행률·검증 상태·실패 및 재시도를 표시한다. 다운로드 파일은 앱 데이터 폴더에 보관하고, 완료 전에 부분 파일을 활성화하지 않는다. 기존 모델이 있으면 보존하고, 같은 모델이 정상 보관돼 있으면 네트워크 요청 없이 재사용한다. 로컬 파일 가져오기는 추가 선택으로 유지한다. 모델 파일 형식·크기·허용 모델의 체크섬을 검증한다. 실패한 모델은 활성화하지 않는다. 모델 교체는 녹음과 추론이 끝난 후 적용한다.

입력 실패 시 기존 클립보드 복구 경로를 보존한다. 무음에서는 문장을 자동 입력하지 않는다. 필요 시 음성 활동 감지를 추가하되 별도 의존성이 필요하면 사전 보안 검사를 적용한다. 기본값으로 원본 음성을 디스크에 저장하지 않는다. 텍스트 이력의 저장·삭제 정책은 화면에서 명시한다.

## 사용자는 네트워크 없이 전체 흐름을 완료한다

로컬 전용 빌드는 클라우드 STT·LLM·인증·결제·계정 갱신·원격 설정·자동 업데이트·원격 에셋 요청을 실행하지 않는다. 초기 모델 다운로드만 인터넷을 사용한다. 사용자가 임의의 다운로드 URL이나 localhost 서버를 지정하는 입력란은 제공하지 않는다. 숨긴 UI만으로 네트워크 차단을 보장하지 않는다. 시작·백그라운드·오류 복구 경로를 함께 검사한다.

패키징은 엔진과 UI 자원을 포함한다. 모델은 설치 후 앱에서 다운로드하므로 설치 파일에 포함하지 않는다. 업데이트는 사용자가 새 앱 패키지를 직접 설치한다. 번들 ID와 앱 표시 이름은 upstream과 구분하고 MIT 고지 및 사용한 엔진·모델의 라이선스를 함께 배포한다.

## 완료 판정

- 단위 검증: 공급자 생성, 설정 검증, 오디오 형식, 무음, 취소, 모델 손상, 동시 실행 및 출력 실패 복구.
- UI 검증: 계정 없이 첫 실행, 권한 거부·재허용, 다운로드 진행률·끊김·재시도·해시 불일치·기존 모델 재사용, 전사 취소와 기존 단축키.
- 통합 검증: 네트워크 차단 상태에서 시작·녹음·전사·입력·재시작이 성공한다. 네트워크가 열린 상태에서도 외부 연결 시도가 없는지 관측한다.
- 한국어 평가: 본인 음성 최소 50문장. 일상 문장, 이름·전문 용어, 숫자·금액·날짜, 한영 혼합, 말 고침, 잡음 및 무음 포함. 원문과 정규화 규칙을 고정하고 CER, 문장별 수정 횟수, 숫자·이름 오류, 무음 오입력을 별도 기록한다.
- 속도 평가: 대상 하드웨어에서 모델 로드, 녹음 종료 후 출력까지 p50/p95, 최대 메모리, 실패율을 기록한다. cold/warm 결과를 분리한다.
- 임시 제품 목표: 10초 발화의 warm p95 출력 지연 3초 이하, 평가 세트 정규화 CER 8% 이하, 무음 오입력 0건. 이는 실측 전 목표이며 보장이 아니다. 목표 미달 시 모델·양자화를 재선택하고 사용자와 기준을 조정한다.

## HTML 선택 항목과 개발 기본값

사용자의 “계획대로 개발한다” 지시에 따라 아래 권장값을 개발 기본값으로 사용한다. HTML에는 범위 변경을 위한 선택 항목을 유지한다.

1. 지원 범위: macOS Apple Silicon부터 시작(권장) / 처음부터 Windows·Linux 포함.
2. 모델 배포(확정): 첫 설치 후 인터넷 다운로드·검증·자동 설정. 이후 받아쓰기는 오프라인이며 수동 파일 가져오기도 지원한다.
3. 기능 범위: 받아쓰기 전용(권장) / 로컬 LLM을 포함한 문장 다듬기. 후자는 별도 모델·메모리·검증 범위가 추가된다.

## html-plan 보안 검사와 남은 작업

사용자가 지정한 스킬: https://github.com/anthropics/claude-plugins-community/blob/main/html-plan/skills/html-plan/SKILL.md

`skillspector scan /tmp/opentypeless-html-plan-skill --no-llm` 결과:

- 점수 100/100, CRITICAL, DO NOT INSTALL.
- 검사 실행 성공, 완전성 partial, coverage 66.7%.
- 미해결 참조, 런타임 난독화 탐지 및 정적 파서 범위 한계.
- pack.mjs의 Credential Access 경고는 비밀 파일 경로를 차단하는 정규식에서 발생했다. 이 부분은 수동 검토상 방어 코드로 보인다.
- 런타임은 localStorage에 응답을 저장하고 사용자 동작으로 클립보드에 복사한다. pack은 로컬 파일을 읽어 HTML에 포함하며 제한된 git 명령을 호출한다.

보수적 판정은 CAUTION이었다. 결과 안내 후 사용자가 스킬을 폴더에 넣고 다시 생성하도록 지시하여 런타임 사용을 승인한 것으로 처리했다. 이후 HTML 런타임으로 `local-stt-plan.packed.html`을 생성했다. 패키징 검사에는 오류가 없었으며, 아직 없는 로컬 엔진 파일 참조 경고 2개가 남았다. 브라우저 정책으로 화면 미리보기는 확인하지 못했다.

구현 현황과 실행 방법은 [LOCAL-DEVELOPMENT.md](LOCAL-DEVELOPMENT.md), 설치 검사 기록은 [installation-review.md](installation-review.md)에 기록한다. PCM 처리 테스트 3개가 통과했다. macOS 디버그 앱 번들 생성, Rust 검사·관련 테스트 14개, 프런트엔드 빌드·lint와 최근 관련 UI 테스트 67개가 통과했다. 앱을 실행해 한국어 모델 입력 화면과 빈 경로 오류를 확인했다. 한국어 정확도·처리 시간 및 네트워크 차단 실기 검증은 아직 완료하지 않았다. 기존 클라우드 테스트 92개의 localStorage 환경 오류는 남아 있다.

## UI 통일 및 지속 검사

사용자가 승인한 @shadcn/lint 0.2.5를 기존 ESLint에 적용했다. 흰색 배경·사이드바와 민트 강조색을 유지하며, 반복된 글자 크기·모서리·색상을 테마 토큰으로 통일한다. Button/Input variant가 외형을 소유하고 화면에서는 배치만 조정한다. 동적 진행률·파형·캡슐 크기는 CSS 변수로 유지한다. 원시 색상·임의 값·인라인 스타일·알 수 없는 클래스·정적 클래스·공유 컴포넌트 스타일 계약을 검사하고 그림자·그라데이션을 금지한다. 상세 기준과 예외는 [design-rules.md](design-rules.md)에 기록한다. 최종 lint 오류/경고 0건, 관련 UI 테스트 251개와 규칙 자체 점검이 통과했다.
